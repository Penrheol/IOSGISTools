# IOSGISTools
GIStools
This folder contains two standalone software tools: the GIS Coverage & Gap Analysis Tool (GIS_Coverage_Gap_Tool_v1.4.html) and the Station Verification Tool (Station_Verification_Tool_v1.3.html), each referenced in the Technical Proposal's Phase 4 and Phase 6 methodology (Observing-System Inventory; GIS, Spatial Coverage and Network Adequacy Analysis).
These are demonstration prototypes for evaluation - not final production tools
